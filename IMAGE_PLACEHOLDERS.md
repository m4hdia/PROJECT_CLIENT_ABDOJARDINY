# Image Placeholders - Premium Gardening Website

This document lists all image placeholders that need to be replaced with unique, realistic, high-quality gardening/landscaping photos.

## Image Requirements

- **Format**: JPG or WebP (optimized for web)
- **Quality**: High resolution (minimum 1920px width for hero images)
- **Style**: Authentic, realistic, diverse - NO stock-looking staged photos
- **Uniqueness**: Each image must be different - no duplicates
- **Optimization**: Provide both original high-res and web-optimized versions

---

## Required Images

### Hero Section
1. **`/images/hero-gardener-working.jpg`** (1920x1080 minimum)
   - **Description**: Full-bleed hero image - gardener working in a garden (pruning, planting, or landscaping)
   - **Style**: Cinematic, immersive, real work in progress
   - **Usage**: Hero background (parallax effect)
   - **Alternative**: Video file `/videos/gardening-hero-loop.mp4` (5-8 seconds, muted, autoplay)

### Before/After Projects

2. **`/images/projects/modern-garden-before.jpg`** (1200x800 minimum)

   - **Description**: After shot of the same modern garden - transformed
   - **Style**: Matching angle, professional finish

   - **Description**: Before shot of traditional courtyard garden

   - **Description**: After shot of restored traditional courtyard
   - **Style**: Matching angle, elegant restoration

   - **Style**: Modern, green oasis in city setting

## How to Add Images

1. Place optimized images in `/public/images/` directory
2. Create subdirectory `/public/images/projects/` for project images
3. For video: Place in `/public/videos/` directory
4. Update image paths in `resources/views/welcome.blade.php` if needed

## Image Optimization Tips

- Use tools like ImageOptim, TinyPNG, or Squoosh for compression
- Convert to WebP format for better performance
- Ensure responsive images using `<picture>` element or `srcset` for critical images
- Lazy load non-critical images with `loading="lazy"` attribute
